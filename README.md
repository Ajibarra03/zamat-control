# ZAMAT Control — V0.1.0

Primera versión pública oficial de ZAMAT Control.

## Plataforma
- Frontend estático publicado en GitHub Pages.
- Datos, autenticación, permisos y tiempo real en Supabase.
- Instalable como aplicación web (PWA) en Android, iPhone/iPad y computadoras compatibles.

## Seguridad
Las claves secretas de Supabase no forman parte del frontend. Las tareas administrativas se ejecutan con Edge Functions.
